
- Giả sử $D$ là tập phương án. Ta cần tìm $X^*\in D$ sao cho $f(X^*)\to\max(\min)$

- Phương pháp được tiến hành như sau
>**Bước 1 Khởi tạo:**
>XOPT = $\varnothing$;    // Phương án tối ưu
>FOPT = $-\infty (+\infty)$  // Giá trị tối ưu
>
>**Bước 2 Lặp:**
>for $(X\in D)$  {       // Lấy mỗi phần tử trên tập phương án
>    $S = f(X)$        // Tính giá trị hàm mục tiêu cho phương án $X$
>    
>    if $(FOTP < S)$ {        // Cập nhật phương án tối ưu
>        $FOTP = S;$			   // Giá trị tối ưu mới
>	 $XOPT = X;$           // Phương án tối ưu mới
>    }
>}
>
>**Bước 3 Trả lại kết quả:**
>Return $(XOPT, FOPT)$

- Ưu điểm: Đơn giản, dễ cài đặt, có thể giải quyết mọi bài toán tối ưu
- Nhược điểm: Chi phí tính toán lớn
