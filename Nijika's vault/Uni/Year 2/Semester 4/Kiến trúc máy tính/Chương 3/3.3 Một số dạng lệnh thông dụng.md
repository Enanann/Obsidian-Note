
# Các lệnh vận chuyển dữ liệu

- Chuyển dữ liệu giữa các thành phần của máy tính

- Ví dụ: Giữa các thanh ghi trong CPU
```
MOVE Ri, Rj; Rj -> Ri
```

- Ví dụ: Giữa thanh ghi CPU và một vị trí trong bộ nhớ
```
MOVE Rj, 1000; M[1000] -> Rj
```

- Ví dụ: Giữa các vị trí trong bộ nhớ
```
MOVE 1000, (Rj); M[Rj] -> M[1000]
```

- Một số lệnh vận chuyển dữ liệu thông dụng
```
MOVE: move data between register-register, memory-register, memory-memory

LOAD: LOAD data from memory into a register

STORE: store data from register to memory

PUSH: push data onto the stack

POP: remove data from the top of the stack
```

# Các lệnh số học và logic

- Thực hiện thao tác số học và logic giữa các thanh ghi và nội dung ô nhớ

- Ví dụ
```
ADD R1, R2, R3; R2 + R3 -> R1

SUBTRACT R1, R2, R3; R2 - R3 -> R1
```

- Các lệnh tính toán số học thông dụng
```
ADD: add two operands

SUBTRACT: subtract two operands

MULTIPLY: multiply two operands

DIVIDE: divide two operands

INCREMENT: increase by 1

DECREMENT: decrease by 1
```

- Các lệnh logic thông dụng
```
NOT:

AND

OR

XOR

COMPARE

SHIFT

ROTATE
```
# Các lệnh điều khiển chương trình

- Dùng để thay đổi trình tự các lệnh được thực hiện
	- Các lệnh rẽ nhánh (nhẩy) có điều kiện (**conditional branching / jump**)
	- Các lệnh rẽ nhánh (nhẩy) không điều kiện (**unconditional branching / jump**)
	- CALL và RETURN: lệnh gọi thực hiện và trở về từ chương trình con

- Đặc tính chung của các lệnh này là quá trình thực hiện lệnh của chúng làm thay đổi giá trị PC

- Sử dụng các cờ ALU để xác định các điều kiện

- Một số lệnh điều khiển thông dụng
```
BRANCH - IF - CONDITION: jump to instruction at new address if the condition is true

JUMP: unconditionally jump to instruction at new address

CALL: jump to a function (and save return address)

RETURN: return from a function and resume program execution
```

- Ví dụ
```
LOAD R1, #1000;
LAP:
	ADD R0, (R2);
	DECREMENT R1;
	BRANCH_IF >0 LAP;
```
$\Rightarrow$ Nạp giá trị 1000 vào R1, sau đó cộng R0 với vị trí M[R2] và giảm R1 đi 1 đơn vị. Tiếp tục nếu R1 > 0

# Các lệnh vào, ra

- Được dùng để truyền dữ liệu giữa máy tính và các thiết bị ngoại vi
- Các thiết bị ngoại vi giao tiếp với máy tính thông qua các cổng. Mỗi cổng có một địa chỉ dành riêng

- Hai lệnh I/O cơ bản được sử dụng 
	- INPUT: dùng để chuyển dữ liệu từ thiết bị ngoại vi vào tới bộ vi xử lý
	- OUTPUT: dùng để chuyển dữ liệu từ VXL ra thiết bị đầu ra

- Ví dụ
```
CLEAR R0;                R0 <- 0
MOVE R1, #100;           R1 <- 100
CLEAR R2;                R2 <- 0
LAP:
	ADD R0, 1000(R2);    R0 <- R0 + M[R2 + 1000]
	INCREMENT R2;        R2 <- R2 + 1
	DECREMENT R1;        R1 <- R1 - 1
	BRANCH_IF >0 LAP;    go to LAP if R1 > 0

STORE 2000, R0;          M[2000] <- R0
```
