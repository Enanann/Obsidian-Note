
# Xung đột tài nguyên

- Xung đột tài nguyên (**Resource conflict**) bao gồm
	- Xung đột truy cập bộ nhớ
	- Xung đột truy cập thanh ghi

- Lý do là tài nguyên không đủ

- Ví dụ: Nếu bộ nhớ chỉ hỗ trợ một thao tác đọc / ghi tại một thời điểm, pipeline yêu cầu 2 truy cập bộ nhớ 1 lúc (đọc lệnh tại IF và đọc dữ liệu tại ID) $\Rightarrow$ Nảy sinh xung đột

- Giải pháp
	- Nâng cao khả năng tài nguyên
	- Memory / cache: Hỗ trợ nhiều thao tác đọc / ghi cùng lúc
	- Chia cache thành cache lệnh và cache dữ liệu để cải thiện truy cập

# Xung đột dữ liệu

- Ví dụ: Xét hai lệnh sau
```
ADD R1, R1, R3; R1 <- R1 + R3
SUB R4, R1, R2; R4 <- R1 - R2
```
- SUB sử dụng kết quả lệnh ADD $\Rightarrow$ có phụ thuộc dữ liệu giữa hai lệnh này
- SUB đọc R1 tại giai đoạn 2 (ID); trong đó ADD lưu kết quả tại giai đoạn 5 (WB)
$\Rightarrow$ SUB đọc giá trị cũ R1 trước khi ADD lưu trữ giá trị mới
$\Rightarrow$ Dữ liệu chưa sẵn sàng cho các lệnh phụ thuộc tiếp theo

- Các khắc phục xung đột dữ liệu
	- Nhận biết nó xảy ra
	- Ngưng pipeline (stall): Phải làm trễ hoặc ngưng pipeline bằng cách sử dụng một vài phương pháp tới khi có dữ liệu chính xác
	- Sử dụng compiler để nhận biết RAW - (**Read after Write**) và:
		- Chèn các lệnh NO-OP vào giữa các lệnh có RAW
		- Thay đổi trình tự trong chương trình và chèn các lệnh độc lập dữ liệu vào vị trí giữa 2 lệnh có RAW
	- Sử dụng phần cứng để xác định RAW (có trong các CPUs hiện đại) và dự đoán trước giá trị dữ liệu phụ thuộc

- Ví dụ: Xác định lỗi và bố trí lại các câu lệnh tránh trì hoãn khi thiết kế pipeline cho các câu lệnh sau
```
LOAD R1, 0(R0)
LOAD R2, 4(R0)
ADD R3, R1, R2
STORE R3, 12(R0)
LOAD R4, 8(R0)
ADD R5, R1, R4
STORE R5, 16(R0)
```

- Xét tính phụ thuộc các lệnh
```
LOAD R1, 0(R0)     - không phụ thuộc 
LOAD R2, 4(R0)     - không phụ thuộc
ADD R3, R1, R2     - phụ thuộc R1, R2
STORE R3, 12(R0)   - phụ thuộc R3
LOAD R4, 8(R0)     - không phụ thuộc
ADD R5, R1, R4     - phụ thuộc R1, R4
STORE R5, 16(R0)   - phụ thuộc R5
```

- Do lệnh đọc dữ liệu vào giai đoạn ID và ghi dữ liệu vào giai đoạn WB, có thể sắp xếp lại và thêm NO-OP như sau
```
LOAD R1, 0(R0)
LOAD R2, 4(R0)
LOAD R4, 8(R0)
NO-OP
ADD R3, R1, R2
ADD R5, R1, R4
NO OP
STORE R3, 12(R0)
STORE R5, 16(R0)
```
