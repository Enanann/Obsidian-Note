
# Lý thuyết

- Tư tưởng
	- Trong quá trình tìm kiếm, ưu tiên "**chiều rộng**" hơn "**chiều sâu**"
	- Tìm kiếm **xung quanh** trước khi **đi xuống** sâu hơn

- Thuật toán
>Sử dụng hàng đợi
```
BFS(u) {
	queue = {}; // Khởi tạo hàng đợi rỗng
	enqueue(queue, u);
	chuaxet[u] = false;
	while (!queue.empty()) {
		s = dequeue(queue); <Thăm đỉnh s>
		for (t in Ke(s)) {
			if (chuaxet[t]) {
				enqueue(queue, t);
				chuaxet[t] = false;
			}
		}
	}
}
```

- Độ phứ tạp của BFS(u) phụ thuộc vào phương pháp biểu diễn đồ thị
	- Biểu diễn bằng ma trận kề: $O(n^2)$, $n$ là số đỉnh
	- Biểu diễn bằng danh sách cạnh: $O(n.m)$, $n$ là số đỉnh, $m$ là số cạnh
	- Biểu diễn bằng danh sách kề: $O(\max(n,m))$, $n$ là số đỉnh, $m$ là số cạnh

- Ví dụ: Cho đồ thị gồm 13 đỉnh, thực hiện BFS(1)
```

```

- Chú ý
	- Với đồ thị vô hướng, nếu $DFS(u)=V$ hoặc $BFS(u)=V$ thì ta có thể kết luận đồ thị liên thông

	- Với đồ thị có hướng, nếu $DFS(u)=V$ hoặc $BFS(u)=V$ thì ta có thể kết luận đồ thị liên thông yếu
