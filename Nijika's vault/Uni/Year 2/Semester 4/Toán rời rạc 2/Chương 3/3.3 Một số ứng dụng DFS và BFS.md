# Tìm đường đi giữa các đỉnh trên đồ thị

### Bài toán

- Cho đồ thị $G=<V,E>$ (**vô hướng hoặc có hướng**), trong đó $V$ là tập đỉnh, $E$ là tập cạnh. Tìm đường đi từ $s\to t$ với $s,t\in V$ 

### Thuật toán

- Mô tả:
	- Nếu $t\in DFS(s)$ hoặc $t\in BFS(s)$ thì ta kết luận là có đường đi từ $s\to t$, ngược lại sẽ không có
	- Để ghi nhận đường đi, ta sử dụng mảng $\text{truoc[ ]}$ gồm $n$ phần tử, với $n=|V|$ 
		- Khởi tạo $\text{truoc[u]=0}$ với mọi $u$
		- Mỗi khi đưa $v \in \text{Ke(u)}$ và ngăn xếp (DFS) hoặc hàng đợi (BFS) thì ta ghi nhận $\text{truoc[v]}=u$ 
		- Nếu DFS và BFS không duyệt được đến đỉnh $t$, khi đó $\text{truoc[t]}=0$ thì ta kết luận không có đường đi từ $s\to t$ 

- Sử dụng DFS
```
DFS(s) {
	stack = {};
	push(stack, s);
	chuaxet[s] = false;
	while (!stack.empty()) {
		u = stack.top();
		found = false;
		for (v in Ke(u)) {
			if (chuaxet[v]) {
				chuaxet[v] = false;
				push(stack, v);
				truoc[v] = u;
				found = true;
				break;
			}
		}

		if (!found) {
			stack.pop();
		}
	}
}
```

- Sử dụng BFS
```
BFS(s) {
	queue = {};
	enqueue(queue, s);
	chuaxet[s] = false;
	while (!queue.empty()) {
		u = dequeue(queue);
		for (v in Ke(u)) {
			if (chuaxet[v]) {
				enqueue(queue, v);
				chuaxet[v] = false;
				truoc[v] = u;
			}
		}
	}
}
```

- Ghi nhận đường đi
```
Ghi-Nhan-Duong-Di(s, t) {
	if (truoc[t] == 0) {
```

# Tính liên thông mạnh trên đồ thị có hướng

### Bài toán

- Đồ thị **có hướng** $G=<V,E>$ là liên thông mạnh nếu giữa hai đỉnh bất kì của nó đều tồn tại đường đi. Cho trước đồ thị có hướng $G=<V,E>$, kiểm tra xem $G$ có liên thông mạnh hay không

### Thuật toán

```
bool Strong-Connected (G=<V,E>) {
	ReInit(); // for u in V : chuaxet[u] = true;
	for (u in V) {
		if (BFS(u) != V) { // Có thể xét DFS(u) != V 
			return false;
		} else {
			ReInit(); // Khởi tạo lại mảng chuaxet[]
		}
	}
	return true;
}
```

# Duyệt các đỉnh trụ

### Bài toán

- Đỉnh $u\in V$ của đồ thị **vô hướng** $G=<V,E>$ được gọi là trụ nếu loại bỏ đỉnh $u$ cùng với các cạnh của nối với $u$ làm tăng thành phần liên thông của $G$. Cho trước đồ thị **vô hướng (liên thông)** $G=<V,E>$, tìm các đỉnh trụ của $G$
	
### Thuật toán

```
Duyet-Tru(G=<V,E>) {
	ReInit(); // for u in V : chuaxet[u] = true;
	for (u in V) { // Lấy mỗi đỉnh u
		chuaxet[u] = false; // cấm BFS hoặc DFS duyệt u
		if (BFS(v) != V\{u}) { // Có thể DFS(v) != V\{u}
			<Ghi nhận u là trụ>;
		}
		ReInit(); // Khởi tạo lại mảng chuaxet[]
	}
}
```

- Note:
	- $v$ là đỉnh bất kì khác $u$, có thể lấy $v$ là đỉnh đầu tiên khác $u$
	- V \ {u} nghĩa là tập các đỉnh đồ thị trừ đi u, hay là $|V|-1$ 

# Duyệt các cạnh cầu

### Bài toán

- Cạnh $e\in E$ của đồ thị **vô hướng** $G=<V,E>$ được gọi là cạnh cầu nếu loại bỏ $e$ làm tăng thành phần liên thông của $G$. Cho trước đồ thị **vô hướng (liên thông)** $G=<V,E>$, tìm các cạnh cầu của $G$

### Thuật toán

```
Duyet-Cau(G=<V,E>) {
	ReInit(); // for u in V : chuaxet[u] = true;
	for (e in E) { // Lấy mỗi cạnh e
		E = E\{e} // Loại bỏ cạnh e ra khỏi đồ thị
		if (BFS(1) != V) { // Có thể kiểm tra DFS(1) != V
			<Ghi nhận e là cạnh cầu>
		}
		E = E + {e}; // Hoàn trả lại cạnh e
		ReInit(); // Khởi tạo lại mảng chuaxet[]
	}
}
```

- Note:
	- Có thể loại bỏ cạnh $e$ bằng cách nếu là [[2.1 Biểu diễn đồ thị bằng ma trận kề|ma trận kề]] $e(x,y)$ với $x, y$ là đỉnh liên thuộc $e$ thì ta có thể dùng $m[x][y]=0; m[y][x]=0$ 

# Định chiều đồ thị

### Định nghĩa

- Phép định chiều đồ thị **vô hướng liên thông** là phép biến đổi đồ thị vô hướng liên thông thành đồ thị **có hướng liên thông mạnh**

- Đồ thị vô hướng $G<V,E>$ được gọi là đồ thị định chiều được nếu có thể dịch chuyển được thành đồ thị có hướng liên thông mạnh bằng cách **định chiều mỗi cạnh vô hướng thành một cung có hướng**
### Định lý

- Đồ thị vô hướng liên thông $G=<V,E>$ **định chiều được** khi và chỉ khi tất cả các cạnh $e\in E$ của $G$ **đều không phải là cầu**

### Một số vấn đề cần quan tâm 

- Chứng minh một đồ thị vô hướng là định chiều được

- Viết chương trình kiểm tra một đồ thị vô hướng có định chiều được hay không

- Chỉ ra một phép định chiều trên một đồ thị vô hướng
