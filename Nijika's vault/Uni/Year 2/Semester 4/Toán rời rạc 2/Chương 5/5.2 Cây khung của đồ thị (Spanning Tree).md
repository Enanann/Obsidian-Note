- **Định nghĩa 3**: Cho $G$ là đồ thị vô hướng liên thông. Ta gọi đồ thị con $T$ của $G$ là một **cây khung** của $G$ (**Cây bao trùm**) nếu $T$ thỏa mãn hai điều kiện
	1. $T$ là một cây
	2. Tập đỉnh của $T$ bằng tập đỉnh của $G$

# Xây dựng cây khung của đồ thị

- Bài toán: Cho đồ thị vô hướng $G=<V,E>$. Hãy xâ dựng một cây khung của đồ thị bắt đầu tại đỉnh $u\in V$ 

- Cách làm
	- Sử dụng DFS hoặc BFS
	- Mỗi khi ta đến được đỉnh $v$ ($chuaxet[v] = true$) từ đỉnh $u$ thì $(u,v)$ được kết nạp vào cây khung

### DFS

- Thuật toán tạo cây khung từ một điểm $u$ 
```
Tree-DFS(u) {
	chuaxet[u] = false;
	for (v in Ke(u)) {
		if (chuaxet[v]) {
			T += (u, v)    // Hợp cạnh (u,v) vào cây khung
			Tree-DFS(v);
		}
	}
}
```

- Thuật toán xây dựng cây khung
```
Tree-Graph-DFS() {
	ReInit();                          // Khởi tạo lại mảng chuaxet
	root = <đỉnh bất kì của đồ thị>;
	T = {};
	Tree-DFS(root);                    // Gọi thuật toán tạo cây khung từ một đỉnh

	if (|T| < n - 1) 
		<đồ thị không liên thông>
	else
		<ghi nhận tập cạnh của cây khung T>
}
```

- Kiểm nghiệm thuật toán: Cho đồ thị **vô hướng** biểu diễn bằng ma trận kề, xây dụng cây khung của đồ thị dùng DFS từ $u=1$

### BFS

- Thuật toán tạo cây khung sử dụng BFS 
```
Tree-BFS(u) {
	T = {};
	queue = {};
	enqueue(queue, u);
	chuaxet[u] = false;
	while (!queue.empty()) {
		s = dequeue(queue);
		for (t in Ke(s)) {
			if (chuaxet[t]) {
				enqueue(queue, t);
				T += (s, t);
				chuaxet[t] = false;
			}
		}
	}

	if (|T| < n - 1) 
		<Đồ thị không liên thông>
	else 
		<Ghi nhận tập cạnh cây khung T>
}
```

- Kiểm nghiệm thuật toán: Cho đồ thị **vô hướng** biểu diễn bằng ma trận kề, xây dụng cây khung của đồ thị dùng BFS từ $u=1$
