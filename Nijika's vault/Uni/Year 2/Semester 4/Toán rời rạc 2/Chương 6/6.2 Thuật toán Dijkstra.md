
# Mục đích

- Sử dụng để tìm đường đi ngắn nhất từ một đỉnh $s$ tới các đỉnh còn lại của đồ thị
- Áp dụng cho **đồ thị có hướng** cới **trọng số không âm**

# Tư tưởng

- Gán nhãn **tạm thời** cho các đỉnh
	- Nhãn của mỗi đỉnh cho beiest cận trên của độ dài đường đi ngắn nhất tới đỉnh đó
- Các nhãn này sẽ được **biến đổi** (tính lại) nhờ một thủ tục lặp
	- Ở mỗi một bước lặp sẽ có một nhãn tạm thời trờ thành nhãn cố định (là độ dài đường đi ngắn nhất từ $s$ tới đỉnh đó)

# Thuật toán và ví dụ

- Mã giả
```c++
Dijkstra(s) {
	// Bước 1: Khởi tạo
	d[s] = 0;               // Gán nhãn đỉnh s là 0
	T = V \ {s};            // T là tập đỉnh có nhãn tạm thời
	for (v in V) {          // Sử dụng s gán nhãn cho các đỉnh còn lại
		d[v] = a(s, v);
		truoc[v] = s;
	}

	// Bước 2: Lặp
	while (!T.empty()) {
		Tìm đỉnh u in T sao cho d[u] = min{d[z] | z in T};
		T = T \ {u};        // Cố định nhãn đỉnh u
		for (v in T) {      // Sử dụng u, gán nhãn lại cho các đỉnh
			if (d[v] > d[u] + a(u, v)) {
				d[v] = d[u] + a(u, v); // Gán nhãn lại cho đỉnh v
				truoc[v] = u;
			}
		}
	}
}
```
