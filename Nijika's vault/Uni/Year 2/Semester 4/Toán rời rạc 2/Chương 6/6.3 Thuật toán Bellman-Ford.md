
# Mục đích 

- Sử dụng để tìm đường đi ngắn nhất từ đỉnh $s$ tới các đỉnh còn lại của đồ thị
- Áp dụng cho **đồ thị có hướng** và **không có chu trình âm** (**Có thể có cạnh âm**)

# Tư tưởng

- Gán nhãn **tạm thời** cho các đỉnh
	- Nhãn mỗi đỉnh sẽ cho biết cận trên của độ dài đường đi ngắn nhất tới đỉnh đó
- Các nhãn này sẽ được **làm tốt dần** (tính lại) nhờ một thủ tục lặp
	- Mỗi khi phát hiện $d[v] > d[u] + a(u,v)$, cập nhật $d[v]=d[u]+a(u,v)$ 

# Thuật toán và ví dụ

- Mã giả
```cpp
Bellman-Ford(s) {
	// Bước 1: Khởi tạo
	for (v in V) { // Sử dụng s gán nhãn cho các đỉnh còn lại 
		d[v] = a(s, v);
		truoc[v] = s;
	}

	// Bước 2: Lặp
	d[s] = 0;
	for (k = 1; k <= n - 1; k++) {
		for (v in V \ {s}) {
			for (u in V) {
				if (d[v] > d[u] + a(u, v)) {
					d[v] = d[u] + a(u, v);
					truoc[v] = u;
				}
			}
		}
	}

}
```
