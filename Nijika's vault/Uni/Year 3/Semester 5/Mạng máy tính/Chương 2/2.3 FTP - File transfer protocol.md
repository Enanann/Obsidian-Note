# Khái niệm

- Trong một phiên truyền tin, người dùng (local host) muốn truyền dữ liệu đến / từ một remote host
![[Pasted image 20250911153838.png]]
- Người dùng tương tác với giao diện FTP (cung cấp tên máy chủ ở xa) -> FTP khởi tạo kết nối TCP với tiến trình FTP ở máy chủ ở xa -> Người dùng cung cấp thông tin nhận dạng (tên, mật khẩu,...) -> FTP server xác định người dùng -> Thực hiện truyền file từ người dùng đến remote (hoặc ngược lại)

- HTTP và FTP đều là các giao thức truyền file
	- Điểm chung: Cùng dùng TCP
	- Điểm khác: 
		- HTTP sử dụng cùng 1 kết nối TCP để gửi yêu cầu và đáp ứng -> Gửi thông tin điều khiển **in-band**
		- FTP sử dụng 2 kết nối TCP song song - **control connection** (gửi các lệnh `put` hay `get`) và **data connection** (gửi file) -> Gửi thông tin điều khiển **out-of-band**

![[Pasted image 20250911155634.png]]

- Khi người dùng bắt đầu một phiên FTP với remote host 
	- Client side tạo kết nối điều khiển TCP đến server side ở cổng 21 -> Gửi dữ liệu nhận dạng người dùng (tên, mật khẩu)
	- Khi server nhận được tín hiệu -> tạo kết nối dữ liệu TCP đến client và gửi duy nhất 1 file
	- Nếu người dùng muốn gửi nhiều file -> Giữ nguyên kết nối điều khiển nhưng tạo nhiều kết nối dữ liệu TCP khác nhau -> Kết nối dữ liệu **không bền vững**
=> FTP là **state**, tức là nó phải lưu trữ trạng thái về người dùng e.g. lưu kết nối điều khiển với một người dùng cụ thể, cũng như theo dõi thư mục hiện tại của người dùng -> Giảm đáng kể các phiên mà FTP có thể duy trì đồng thời

# Các lệnh và đáp ứng của FTP

- Các lệnh được gửi như các văn bản dạng mã 7-bit ASCII qua kênh điều khiển 
```
USER username: User identification 
PASS password: User password
LIST:          Send back a list of all the files in the current directory
RETR filename: Retrive (get) a file from the current directory 
STOR filename: Store (put) a file into the current directory/remote host
```

- Các mã lệnh trả về thường tương ứng 1-1 đối với các lệnh đưa ra
```
• 331 Username OK, password required
• 125 Data connection already open; transfer starting
• 425 Can’t open data connection
• 452 Error writing file
```
